# Trippr

A mobile-first web application that helps families and groups of friends organize trips with hyper-personalized recommendations.

## Features (Planned)

- Collaborative trip planning with roles (owner, editor, viewer)
- Day-by-day itinerary builder with drag-and-drop
- Google Maps saved list import for personalized suggestions
- Social media post ingestion for trip inspiration
- Expense splitting and group polls
- Offline-capable PWA

## Tech Stack

- **Frontend**: Next.js 14+, React 18+, TypeScript, Tailwind CSS
- **Backend**: Next.js Route Handlers, Zod validation
- **Database**: PostgreSQL, Prisma ORM
- **Auth**: NextAuth.js (Google OAuth, email/password)
- **Testing**: Vitest, Playwright, React Testing Library

## Getting Started

```bash
npm install
npm run dev
```
